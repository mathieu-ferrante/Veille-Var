# VeilleIA – Veille IA automatisée pour la DSI du Département du Var

Outil de veille technique et réglementaire sur l'intelligence artificielle, automatisé par un service d'IA.

> Projet réalisé pour l'épreuve **E2** du titre professionnel *Développeur en intelligence artificielle*
> (RNCP37827, bloc 2 – compétences C6, C7, C8). Scénario prospectif.

Projet en cours de construction.
